Forgotten Gears

Présentation

Informations :
Moteur : Unity
Type de projet : Projet scolaire
Mon rôle: Game Programmer
Taille du groupe : 5 personnes
Temps de développement : 4 mois


Forgotten Gears est un projet semestriel de ma seconde année de bachelor à l'ICAN Lille.
Dans Forgotten Gears, le joueur doit compléter des systèmes d'engrenages et explorer son environnement pour découvrir l'histoire d'un ancien peuple.

Système d'engrenages

Le système d'engrenages à été la partie que j'ai le plus apprécié développer. Le jeu appelle une fonction récursive pour faire tourner l'ensemble des rouages. Un des challenge de ce système à été d'éviter les stacks overflow, mais surtout de detecter si une chaîne ne peut pas tourner à cause de deux engrenages tourne dans le même sens (feature qui, malheureusement, n'as pas pue être intégré dans le level design).

Custom Character Controller

Pour ce projet, j'ai créée un Character Controller custom. Le Controller implémente les features suivantes :

- Detection des collisions
- Gestion des sauts
- Paramètres de customisation

Widget World-Space

Un travail particulier à été fournis pour pouvoir rendre diégétique les interfaces du jeu. Passer en World-Space nos interfaces posent des contraintes sur la manière de les construire. De plus, il faut s'assurer que les interfaces reagissent au curseur du joueur.
